# Smart Order Allocation System

A full-stack application developed for the DartCodes Software Engineer Intern Technical Assessment.

## Overview

The Smart Order Allocation System automatically assigns customer orders to a suitable branch based on factors such as stock availability, customer location, and branch workload.

## Planned Technology Stack

- Frontend: React
- Backend: Node.js and Express.js
- Database: MongoDB
- Authentication: JWT
- AI/ML: Python and scikit-learn
